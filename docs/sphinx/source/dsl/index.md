# DSL authoring

[`motion-spec-dsl`](https://github.com/secorolab/motion-spec-dsl) defines the
`.robmot` authoring language and emits the RDF dataset consumed by `motion-spec`.
This section is its user documentation; the DSL repository contains only package
and contributor information.

Read [DSL concepts](concepts.md) for the complete language surface, then work
through the [`pick_place_single` tutorial](tutorials/single-arm.md).
